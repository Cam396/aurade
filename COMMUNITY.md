# AuraDE community

AuraDE is built in the open by people who enjoy making a calm, useful Linux
desktop. The community is for questions, screenshots, testing, ideas, and
friendly technical discussion.

## Where to talk

- Use GitHub Issues for reproducible bugs.
- Use GitHub Discussions for questions, design ideas, and longer conversations.
- Share themes, screenshots, and hardware notes only after removing personal
  information and private logs.
- Use the private security process in SECURITY.md for vulnerabilities. Do not
  report them in a public issue or chat.

If a community chat is linked from the project page, its public rooms should
be enough to get started: welcome, rules, general discussion, support,
development, and showcases. Moderation notes, permission audits, and private
coordination do not belong in this repository.

## A good bug report

Please include:

1. The AuraDE release or commit.
2. The hardware family and firmware mode.
3. What you expected and what happened.
4. A short, redacted log excerpt or a reliable reproduction.
5. Whether the problem survives a reboot or a second attempt.

Never include passwords, API keys, private keys, serial numbers, IP addresses,
or an unredacted diagnostic bundle.

## Community standards

Be patient with new users, assume good faith, and keep criticism about the
work rather than the person. Harassment, discrimination, doxxing, spam, and
deliberate distribution of unsafe images are not welcome. See
CODE_OF_CONDUCT.md for the full policy.
