# Code of Conduct

AuraDE contributors are expected to be constructive, respectful, and precise.
Harassment, discrimination, threats, doxxing, deliberate credential exposure,
and personal attacks are not acceptable in issues, reviews, or chat.

Project maintainers may remove abusive content, close discussions, or limit
participation when needed to keep the project safe. Report conduct concerns
privately through the security contact in [SECURITY.md](SECURITY.md) or by
private message to the repository maintainers; do not include sensitive details
in a public issue.
