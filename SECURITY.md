# Security Policy

AuraDE is pre-release software. No release branch currently receives a stated
security-support lifetime.

Do not file suspected vulnerabilities in a public issue tracker. Use GitHub's
private security-advisory flow:

https://github.com/Cam396/aurade/security/advisories/new

If the advisory button is unavailable, contact the repository maintainer by
private GitHub message and do not include exploit details in a public issue.
The pre-alpha project has no guaranteed response time or supported-version
lifetime yet. A supported public release requires an authenticated security
contact, response targets, and a published signing-key fingerprint.

Release artifacts are trustworthy only when their package and repository
signatures validate against the separately published AuraDE production key.
Unsigned soak artifacts are for controlled development testing only.
